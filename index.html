Clover georeference test

Katsushika Hokusai's The Great Wave off Kanagawa, the Minneapolis Institute of Art's impression as published on Understory, with an AnnotationPage added through the Viewer's annotations attribute: assets/annotations/test-annotations.json. It holds one annotation: Mount Fuji, a region of the print tagged with a GeoJSON point at the mountain's summit (IIIF Cookbook recipe 0139). Open it from the Annotations button on the image or from Annotations in the panel.

View this example on GitHub.

Code

<script src="https://cdn.jsdelivr.net/npm/@nulib/clover/dist/web-components/index.umd.js"></script>

<clover-viewer
  iiif-content="https://iiif-understory.dc.library.northwestern.edu/published/presentation/manifest/12e964fd-532c-4c17-8f09-da8ec9d3bbe1/manifest.json"
  template="default"
  items="grid"
  header="false"
  annotations="assets/annotations/test-annotations.json"
>
</clover-viewer>

The annotation

{
  "id": "…/test-annotations.json/mount-fuji",
  "type": "Annotation",
  "motivation": "tagging",
  "body": {
    "type": "Feature",
    "properties": { "label": { "en": ["Mount Fuji"] } },
    "geometry": { "type": "Point", "coordinates": [138.7274, 35.3606] }
  },
  "target": {
    "type": "SpecificResource",
    "source": {
      "id": "https://iiif-understory.dc.library.northwestern.edu/published/presentation/manifest/12e964fd-532c-4c17-8f09-da8ec9d3bbe1/canvas/0",
      "type": "Canvas",
      "partOf": [{ "id": "https://iiif-understory.dc.library.northwestern.edu/published/presentation/manifest/12e964fd-532c-4c17-8f09-da8ec9d3bbe1/manifest.json", "type": "Manifest" }]
    },
    "selector": {
      "type": "FragmentSelector",
      "conformsTo": "http://www.w3.org/TR/media-frags/",
      "value": "xywh=5520,4140,1080,540"
    }
  }
}

Steps

  1. Load Clover's script in the page's <head>.
  2. Write an AnnotationPage whose annotation targets a region of the Canvas and whose body is a GeoJSON Feature with a Point, and save it beside the page.
  3. Give the Viewer the Manifest as iiif-content and the file as annotations.

Gotchas

  • GeoJSON writes a point as longitude, then latitude: [138.7274, 35.3606], never the other way around.
  • The region is in the Canvas's own pixels, 9568 × 6583 here, never those of a smaller copy of its image.
  • The annotation must target the Canvas by its exact id. Naming its Manifest in partOf lets the AnnotationPage be opened as iiif-content on its own, too.
  • This is a point tagging a place (tagging), not a georeference that lays the image on a map (georeferencing), which needs control points and suits a map rather than a print.
  • A relative path resolves against the page's address, not the site's root. On a GitHub Pages project site, ../../assets/… from the homepage leaves the repository's folder and fails to load.
