Clover georeference test

Katsushika Hokusai's The Great Wave off Kanagawa, the Minneapolis Institute of Art's impression as published on Understory, opened through an AnnotationPage given as the Viewer's iiif-content: assets/annotations/test-annotations.json. Each annotation names the Manifest it belongs to, so Clover opens that Manifest with them. The page holds two:

  • View from Edo Bay, a georeference that lays the whole print over the bay off Kanagawa, today's Tokyo Bay off Yokohama. The Viewer opens on the map with the print in place.
  • Mount Fuji, the mountain's region of the print tagged with a GeoJSON point at its summit (IIIF Cookbook recipe 0139). Picking it frames Fuji and shows the point on a map.

View this example on GitHub.

Code

<script src="https://cdn.jsdelivr.net/npm/@nulib/clover/dist/web-components/index.umd.js"></script>

<clover-viewer
  iiif-content="https://mathewjordan.github.io/clover-georeference-test/assets/annotations/test-annotations.json"
  template="default"
  items="grid"
  header="false"
>
</clover-viewer>

Steps

  1. Load Clover's script in the page's <head>.
  2. Write an AnnotationPage whose annotations target the Canvas and name its Manifest in partOf, and publish it.
  3. Give the Viewer the AnnotationPage's full address as iiif-content.

Gotchas

  • A georeferencing annotation is read only from the content, or from the Manifest's own annotation pages. Given through the Viewer's annotations attribute beside a Manifest, it is left out (Clover 4.12.3), though a tagging point there still shows.
  • iiif-content takes a full address. A relative path such as assets/… fails with "Unreadable iiifContent", although the annotations attribute accepts one.
  • Each annotation needs its Manifest in partOf, or Clover has no Manifest to open.
  • GeoJSON writes a point as longitude, then latitude: [138.7274, 35.3606], never the other way around.
  • Regions and resourceCoords are in the Canvas's own pixels, 9568 × 6583 here, never those of a smaller copy of its image.
  • Exactly where Hokusai imagined standing off Kanagawa is not settled, so the georeference is an approximation: open water east of the old Kanagawa post town.
