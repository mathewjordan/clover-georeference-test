Clover georeference test

Katsushika Hokusai's The Great Wave off Kanagawa, the Minneapolis Institute of Art's impression as published on Understory, opened from its Manifest with an AnnotationPage sideloaded through the Viewer's annotations: assets/annotations/test-annotations.json. Clover lays each annotation on the Canvas it targets, as if the Manifest held it. The page holds two:

  • View from Edo Bay, a georeference that lays the whole print over the bay off Kanagawa, today's Tokyo Bay off Yokohama. Pressing it in Annotations opens the map with the print in place.
  • Mount Fuji, the mountain's region of the print tagged with a GeoJSON point at its summit (IIIF Cookbook recipe 0139). Picking it frames Fuji and shows the point on a map.

View this example on GitHub.

Code

<script src="https://cdn.jsdelivr.net/npm/@nulib/clover@4.12.5/dist/web-components/index.umd.js"></script>

<clover-viewer

  template="default"
  items="grid"
  header="false"

</clover-viewer>

The georeference

Steps

  1. Load Clover's script, 4.12.5 or later, in the page's <head>.
  2. Write an AnnotationPage whose annotations target the Manifest's Canvas, and publish it beside the page.
  3. Give the Viewer the Manifest as iiif-content and the AnnotationPage as annotations.

Gotchas

  • A georeferencing annotation given through annotations is laid on its Canvas from Clover 4.12.5; earlier releases left it out. The script is pinned to that release, as an address without a version can serve an older one for days.
  • iiif-content takes a full address. A relative path such as assets/… fails with "Unreadable iiifContent", although annotations accepts one, as here.
  • An annotation lies on the Canvas its target names by id, so the id must be the Manifest's own. Each also names its Manifest in partOf, so the AnnotationPage still opens on its own as iiif-content.
  • GeoJSON writes a point as longitude, then latitude: [138.7274, 35.3606], never the other way around.
  • Regions and resourceCoords are in the Canvas's own pixels, 9568 × 6583 here, never those of a smaller copy of its image.
  • Exactly where Hokusai imagined standing off Kanagawa is not settled, so the georeference is an approximation: open water out in the bay, off the old Kanagawa post town.
